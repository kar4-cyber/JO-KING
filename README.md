# 👑 JO-KING

A clean, minimalist web application to browse universal clean jokes across 15 categories, featuring a single-click regenerate action and persistent favorites management.

## Features
* **15 Joke Categories**: Access a wide variety of universal clean jokes fetched dynamically via API.
* **Minimalist UI**: Clutter-free design with a single "Regenerate" button and zero unnecessary text.
* **Persistent Favorites**: Save your favorite jokes and keep them stored for your session.
